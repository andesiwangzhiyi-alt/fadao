# 法渡 · 法考学习工具

参考粉笔 AI 训练营思路、按法考学习规律设计的法律职业资格考试刷题工具。纯前端零依赖，离线可用，数据本地存储。

## 功能

- **客观题刷题**：18 个部门法全覆盖（刑法/民法/刑诉/民诉/行政法/商经知/理论法/三国法…），支持单选、多选、不定项三种题型
- **逐选项解析**：每道题附选项级解析（"A项错误…B项正确…"），吃透每个选项对错理由
- **每日一练**：每天 10 题，按部门法权重交叉组卷（刑法/民法/两大诉讼法/行政法/商经为主）
- **模拟考试**：按法考客观题结构组卷（单选:多选:不定项 ≈ 50:35:15），计时作答
- **错题本**：错题自动收录，按艾宾浩斯遗忘曲线（1/2/4/7/15 天）提醒复习，可标记掌握
- **学习统计**：正确率、打卡热力图、连续打卡、薄弱模块分析
- **番茄专注钟**：25 分钟专注法考复习
- **数据管理**：导出/导入 JSON 备份

## 题库

- **总量**：1532 题（单选题 638 / 多选题 810 / 不定项 84）
- **来源**：竹马法考（zhumavip.com，众合教育）真题库，2026-08 抓取整理
- **年份**：2016-2025 法考/司考真题（2025 年 305 题、2024 年 274 题、2023 年 205 题…）
- **解析率**：100% 题目含逐选项解析
- **题号规则**：2018 前=年份+卷别+题号；2018 后=年份+卷别+部门法编号+题号（1民法 2刑法 3行政法 4民诉 5刑诉 6商经知 7理论法 8三国法）

## 使用

直接打开 `index.html` 即可（或部署到任意静态托管）。数据保存在浏览器 localStorage。
